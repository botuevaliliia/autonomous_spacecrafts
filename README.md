# Meet Me in Orbit

**Someone is waiting. Gravity has other plans.**

Find your way to Aster, a moving station above Mars. A little thrust changes your path; good timing brings you together. Every attempt starts with Aster somewhere new.

Learn gravity by playing with it: predict, burn, coast, and discover why getting close is only half the journey.

Real orbital physics. No aerospace background needed.

### Take flight

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[basilisk]'
./start_game.sh
```

Open [the game](http://127.0.0.1:8000/play/) and click **How to play**. Python 3.11+; omit `[basilisk]` to use the fallback.
